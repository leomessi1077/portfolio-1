# portfolio-1

Full-stack portfolio built with React and Vite, with an Express API and MongoDB-backed analytics/contact archive.

## Run locally

1. Install dependencies with `npm run install:all` from the project root.
2. Copy `server/.env.example` to `server/.env` and fill in the local values.
3. Start the API with `npm run dev:server` and the frontend with `npm run dev:client` in separate terminals.

See [VERCEL_DEPLOYMENT.md](VERCEL_DEPLOYMENT.md) for the two-project Vercel setup and production environment variables.
